# Ascend Platform

Crie uma plataforma SaaS premium chamada "Projeto X".

Quero uma interface moderna, profissional e sofisticada, com aparência de software de grande empresa, totalmente responsiva para desktop e celular.

IMPORTANTE:

- Nesta primeira etapa crie apenas o FRONT-END.

- Não conecte Supabase ainda.

- Não crie pagamentos reais.

- Não use APIs externas ainda.

- Use dados fictícios/mockados para preencher o dashboard.

- O projeto precisa ficar organizado para conectarmos o backend depois.

- Não crie uma landing page de vendas. Quero a ÁREA INTERNA DO SISTEMA após o login.

TECNOLOGIA:

- React

- TypeScript

- Vite

- Tailwind CSS

- Componentes modernos e reutilizáveis

- Código organizado por componentes e páginas

IDENTIDADE VISUAL:

- Nome: Projeto X

- Visual limpo e tecnológico

- Cor de destaque azul/violeta

- Cards com bordas suaves e sombras discretas

- Ícones modernos

- Tipografia profissional

- Nada infantil ou exageradamente colorido

RESPONSIVIDADE:

No celular a sidebar deve virar um menu lateral/hambúrguer.

Cards devem se reorganizar corretamente.

Não permitir conteúdo vazando para fora da tela.

ROTAS:

Crie uma rota/página inicial para cada item do menu.

As páginas que ainda não possuem funcionalidades podem mostrar um cabeçalho profissional e uma mensagem "Módulo em desenvolvimento".

Quero que o Dashboard fique visualmente completo e impressionante.

Não implemente funcionalidades reais agora.

Primeiro construa uma base visual premium, consistente e fácil de expandir.
